# Sample documents

Fictional files for trying Citewise locally:

- `northwind-annual-report-2025.pdf`: a 4-page annual report (revenue, headcount, risks, outlook)
- `travel-policy.md`: a short Markdown policy with headings

Try asking: *"What was revenue in 2025 and how fast did it grow?"*, *"How many employees are there?"*,
*"What's the per diem in Europe?"*
